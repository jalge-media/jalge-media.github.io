1. 수집하는 정보

잘게는 이용자의 개인정보를 수집하지 않습니다. 운영 도구는 잘게가 소유한 계정에 대해서만 Google(YouTube)·Instagram의 인증 정보를 사용하며, 다른 사람의 계정이나 데이터에 접근하지 않습니다.

2. Google 사용자 데이터의 이용

잘게의 Google API 사용은 제한된 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.

3. 보관과 삭제

인증 정보는 연결을 해제하면 삭제합니다. Google 계정의 보안 설정에서 언제든 접근 권한을 철회할 수 있습니다.
